# Проект Sprint_5 по автоматизации UI-тестирования для учебного сервиса «Доска».

## Функциональности, покрытые тестами:
- #### Регистрация пользователя:

  - Успешная регистрация нового пользователя.

  - Попытка регистрации с некорректным email.

  - Попытка регистрации уже существующего пользователя.

- #### Аутентификация:

  - Успешный вход пользователя в систему (Login).

  - Выход пользователя из системы (Logout).

- #### Управление объявлениями:

  - Проверка невозможности создать объявление неавторизованным пользователем.

  - Успешное создание нового объявления авторизованным пользователем.

## Зависимости:
- pytest
- selenium 
- faker

## Структура проекта

- `locators.py` - содержит локаторы элементов страниц
- `tests/conftest.py` - фикстуры pytest
- `tests/` - содержит тесты
